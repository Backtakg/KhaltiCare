# KhaltiCare

An independent, zero-cost UX concept prototype exploring clearer KYC progress, support-case ownership, and payment-issue status.

**This is not an official Khalti or IME Pay product.** It is not affiliated with, endorsed by, or connected to either company.

## Run locally
Open `index.html` in a browser. No build step, framework, API key, backend, or paid service is required.

## Publish
Enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main` → `/ (root)`).

## Demo features
- KYC progress timeline with a clear current status and next step
- Create local sample support cases and inspect their update history
- Payment issue reporting with fictional amounts and local-only demo records
- Responsive layout for mobile and desktop
- Demo records are stored in the browser's localStorage

## Privacy and limitations
- All sample IDs, names, amounts, dates, and statuses are fictional.
- No information is sent to a server.
- Do not enter real wallet credentials, OTPs, citizenship details, bank details, or private payment information.
- This prototype cannot access or change real Khalti accounts, KYC requests, transactions, or support tickets.
